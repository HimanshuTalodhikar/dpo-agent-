Connect DPDP Agent to Claude Desktop

Enable real-time legal automation directly inside your Claude Desktop conversation interface via the Model Context Protocol (MCP).

1

Run Automated Setup Command

Open your terminal or PowerShell and run the one-line setup command for your OS:

# macOS Terminal Setup Command:
mkdir -p "$HOME/Library/Application Support/Claude" && \
cp "/Users/himanshu/desktop/cloagent/scripts/mcp_bridge.py" "$HOME/Library/Application Support/Claude/mcp_bridge.py" && \
cat << 'EOF' > "$HOME/Library/Application Support/Claude/claude_desktop_config.json"
{
  "mcpServers": {
    "dpdp-agent": {
      "command": "/usr/bin/python3",
      "args": [
        "/Users/himanshu/Library/Application Support/Claude/mcp_bridge.py"
      ]
    }
  }
}
EOF
# Windows PowerShell Setup Command:
New-Item -ItemType Directory -Force -Path "$env:APPDATA\Claude"
Set-Content -Path "$env:APPDATA\Claude\mcp_bridge.py" -Value (Invoke-WebRequest -Uri "http://cloagent-alb-896741255.ap-south-1.elb.amazonaws.com/mcp_bridge.py").Content
Set-Content -Path "$env:APPDATA\Claude\claude_desktop_config.json" -Value @'
{
  "mcpServers": {
    "dpdp-agent": {
      "command": "python",
      "args": [
        "%APPDATA%\\Claude\\mcp_bridge.py"
      ]
    }
  }
}
'@
# Linux Bash Setup Command:
mkdir -p "$HOME/.config/Claude" && \
cat << 'EOF' > "$HOME/.config/Claude/claude_desktop_config.json"
{
  "mcpServers": {
    "dpdp-agent": {
      "command": "python3",
      "args": [
        "/path/to/mcp_bridge.py"
      ]
    }
  }
}
EOF
